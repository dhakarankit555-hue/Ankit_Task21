# Task 21 - Onion Food Website

## Description

This project is a responsive food delivery website created as part of the MERN training task.

The website provides healthy food information, city details, customer testimonials and different pricing plans.

## Features

- Responsive food delivery website
- Hero section with background image
- Navigation menu
- How It Works section
- Cities section with city details
- Customer testimonials
- Pricing plans
- Pricing card hover animation
- Sign Up buttons
- Responsive design for mobile devices
- Mobile logo introduction screen
- Smooth scrolling navigation
- Footer with contact information

## Technologies Used

- HTML
- CSS
- JavaScript

## Images

The project uses locally stored images for:

- Website logo
- Home background
- Cities
- Testimonials
- Pricing background

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.

## Responsive Breakpoints

- Up to 1100px: Navigation changes to a hamburger menu for tablets and smaller screens.
- Up to 900px: Content sections adjust into smaller layouts for tablet screens.
- Up to 600px: Mobile layout is applied with a centered logo, hamburger menu, stacked cards and smaller text.
